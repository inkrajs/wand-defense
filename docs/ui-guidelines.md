# 游戏界面规范

以下为用户试玩反馈确认的当前要求，后续开发与代码审查按此维护。
视觉效果仍由用户验收，类型检查不代表视觉通过。

## 强制反馈基准

- 除非用户明确要求，默认不展示任何泛化操作提示：成功、已完成、已提交、
  raw错误码、浮动消息、toast及交易结果区一律不加。
- 通过真实状态、物品位置和合法目标反馈操作结果；拒绝操作保留原状态。
- 必需的读屏播报使用视觉隐藏内容，结构化命令结果和开发诊断仍保留。
  用户主动查询的属性、连接状态等真实产品内容不属于泛化操作提示。

## 画面与导航

- 一个游戏画面填满应用视口，页面外没有额外操作区或滚动内容。
- 顶部中央只显示波次和当前状态；左上显示金币图标与数量。
- 右上是无边框图标菜单，进入覆盖全画面的二级菜单页；选项居中，
  再进入详情页，沿用统一菜单配置和返回机制。
- 左下是无边框背包图标，右下是角色入口及其左侧的领地入口，使用相同32px图标和44px点击区域。法杖不是另一个图标，而是可直接编排的插槽网格，
  准备状态在游戏区域中央，“开始游戏”位于其下；战斗时移动到底部并用 transform 缩为五分之一。
  战斗缩略网格只读，不要求在微小目标上操作；完整编辑仍可通过背包进入。
  容器占位随可见尺寸收敛，减少动态效果时关闭位移动画。该面板只显示槽位，
  不放标题、等级、选择器、说明或额外操作按钮。
- 第0波中央操作为“开始游戏”，后续为“开始下一波”。
  有结算内容时，按钮在结算内容上方，领奖前不绕过领取流程。
  准备阶段打开背包不隐藏开始按钮；开始命令原子收起背包并清除准备暂停后开战。
- 初始角色横向居中，多个角色围绕中心排列；坐标与法术来源保持对应。
- 角色入口只替换中央法杖工作区，保留主游戏壳和背包分区，不跳转为全屏详情页。
  中央立绘左右各3槽，无头顶/脚底槽；槽位仅图标/物品图，不显示名称、空位、尺寸、等级或品级文字。
  删除“返回游戏”和角色姓名/等级/品级header，右下角色按钮toggle关闭。
  详情内不重复提供切换角色按钮，统一从下方场景角色图标切换，详情读取同一当前角色。
  右侧内容进一步分为概览、属性、途径、成长；最右侧为竖向纯图标Tabs，无可见Tab文字。
  概览只用“图标→短属性名→数值”关键行；雷达独立放属性页，无标题、轴范围说明、图例、值表或重复概览。
  途径/成长按用户主动选页显示必要真实内容，不默认展开长篇摘要。
  必要语义进入ARIA而非画面；不通过缩小文字来容纳冗余信息，不实现已暂缓的实际升级。
  桌面充分利用左右宽度布局，组件自身保持紧凑，小屏再收拢，不把所有区域挤在中央窄列。
- 背包是固定三行可见物品的下方分区，展开真实挤压上方游戏区域；
  不提供拖动分隔条或尺寸调整，关闭后不保留空白占位；外层只有上分隔线，使用公共 PencilLine，不用原生 border-top 另造风格。
  列数按当前屏幕实际可用宽度计算，不人为限制为六列；各分类使用相同格子尺寸和容量。
  仅物品区在超过三行时纵向滚动，不横向滚动；Tabs和上区固定，物品本身仍可拖放。
  分类依次魔法、物品、装备；物品保留真实形状，
  通过受控 InventoryGrid 适配器提交布局/装备命令，归属规则不由 UI 另行复制。
- 已确认队伍共享库存，切换角色仅切换法杖与装备视图。
- 移动、装入、移出或领取一个物品后，其他物品保留原位置，不自动压紧重排整个背包。
  新物品寻找空位；同类合并保留目标位置。屏宽变化时仅处理真正越界或冲突的位置。
- 背包可见内容只保留一排分类 Tabs 和物品格；去除背包标题、格子区域标题、
  分类下解释和底部操作介绍。必要的无障碍名称/说明和操作失败反馈保留。
  所有 Tabs 使用公共 Inkra Tabs，必须有与场景匹配的 PencilIcon；无现成图形则绘制，
  不以无图标的 Button 导航假充 Tabs。中文标签统一两个字，背包依次为魔法、物品、装备；
  使用 Tabs.List divided 在选项间显示库分割线，切换动画结束后仍保留选中笔触。
- 左下背包按钮同时负责展开与关闭；展开时有选中背景，悬停有手绘背景反馈，
  不再在库存内另放标题或关闭按钮。按钮的 aria-expanded 与真实展开状态同步。
  Tabs 右侧不展示额外 actions 按钮。
- 场景点击角色与角色页选择使用同一 activeCharacterId；选中用库 selection 圆形背景涂色，不叠硬框或第三圈环。
  选中底色完整位于蓝色法力环内侧并留间距，不铺到外层绿色经验环；人物中央也可点击。
  法杖区显示当前角色全部合法已装备法杖，仅槽位；法杖与开始按钮作为一组垂直居中。
- 进入菜单保留同一运行时并暂停；返回恢复之前的暂停状态。
  Agent连接组件切换页面时保持挂载，隐藏不等于断开。
- 右上从左到右为减速、当前速度、加速、暂停/继续、菜单。
  速度按 0.25/0.5/0.75/1/2/3/5 相邻步进，边界禁用，不循环；2倍减为1倍。
  准备中不展示“已暂停”覆盖层；显式暂停只在战斗阶段有此反馈。
- UI 出入、法杖位移和缩放有一致过渡，尊重系统及设置的减少动态效果。

## 奖励区域

- 结算时用横向奖励卡替换中央法杖/开始下一波整组，不套外层大卡、不加标题说明或整理背包入口。
- 每项只有一层可见卡面：上方空图片区、中间标题、下方短介绍；品级颜色按奖励数据呈现。
- 主体区域点击领取，右下独立区域翻面查看真实详细属性；无“选择奖励”“翻转”等可见按钮或操作文字。
  保留透明语义点击区、键盘与读屏名称；翻面不能误领取，卡面和边框一起旋转，减少动态时直接切换。
- 领取后由运行时决定物品入共享背包、角色入队、法杖未装备或本局增幅等去向，UI不复制交易规则。

## 物品外观

- 属性以整块物品真实占格轮廓内的背景涂色区分，跨格和旋转后一致，不只染文字或图标标签。
- 品级通过完整物品外轮廓边框区分，与属性填色独立；法杖与背包使用同一外观映射。
- 不用标签小卡片或矩形外接框冒充异形物品的完整着色。

## 状态条

- 角色经验采用绿色 Progress circular，法力采用蓝色圆环，人物在两个同心环中央，无可见数字。
  当前经验属于本局共享成长，未实现角色独立经验，不能虚构独立进度。
- 护盾条在上、生命条在下，均用 Progress linear，放在角色下方的防线虚线处。
  条底部与下方图标入口顶部统一12px，角色与条顶也统一12px，不按视口百分比拉大留白。
- 满值填色横贯战场，减少时两端对称向中心收缩；生命使用 danger 红色语义色。
- 只展示涂色效果，无数字、装饰外框、滑块或可拖动调值交互。
  真实 value/max 和辅助技术语义仍保留。
- npm 0.15.0 没有 fillOrigin 属性，居中裁切仅在游戏的 Progress 样式作用域中适配，
  继续使用组件自身的 PencilSurface 填色，不伪造满值代替真实进度。
- 当前圆形 Progress 与 CircularSlider 共用笔触圆环，linear 则用矩形填色。
  用户希望同款笔触拉成直条，这是待库层补齐的视觉能力；
  不通过拉伸圆环、私有renderer或隐藏交互Slider来冒充现有Progress支持。
- 本机候选已接入公开 stroke/showTrack/fillOrigin/color/thickness，细条8px、条组20px，
  该模式去掉旧裁切适配。原npm模式仍12px、条组28px；角色和魔法发射位置跟同一条组高度变量。

## Inkra 使用与间距

- 使用实际安装的 @inkra/react 0.15.0 公开 API。在线文档快照0.14.0仅作参考，
  组件名称、属性与导出以安装包公开声明为准，不访问库内部渲染 API。
- 图标入口使用 Button size=icon variant=ghost 与 PencilIcon。
  图标以稳定 seed、统一画布尺寸呈现，无可见按钮名，保留 aria-label。
  不叠加纯色 hover 底；游戏局部移除 ghost icon 的 fallback 背景，保留笔触、焦点和 forced-colors 支持。
- HUD、菜单、标题及短说明使用 PencilText；Button等已有文字渲染直接复用。
  URL/配对信息保持可复制的原生文本语义。
- 面板使用 PencilSurface，字体、颜色、间距、圆角使用库语义 tokens。
  保持默认主题继承；不另造一套按钮边框、阴影和字重皮肤。
- 四角布局用同一个 HUD inset：同一角横纵距离一致，各角也一致；
  安全区域统一纳入 inset，不散落多个独立8/12/16px覆盖。
- 使用4px间距网格。全屏页面不套阅读页 max-width，
  长内容仅在所属面板内部滚动。
- HUD、菜单选项和槽位外围不加无意义卡片外框或多层padding。
  角色位于虚线防线上方，取消半圆领地色块、城堡和底部颜色示意。

## 魔法表现

- 命中事件提供公开坐标，表现层按事件序号消费，不回放初次挂载前的旧事件。
- 火花/火球有火焰弹、短尾迹和命中火花；金针与回春有独立简洁效果。
  水弹、雷矢、风刃、岩弹分别有水滴、闪电、弧刃、岩块形状及各自命中表现，不只给火焰换色。
  效果映射可替换。飞行直接呈现真实弹体实体，命中事件只展示冲击，不把装饰动画当第二套伤害规则。
- 有界短期效果、无永久绘图循环；减少动态效果时取消额外尾迹、位移插值和扩散，仍保留权威弹体位置及短暂静态命中反馈。
- 新怪从低速平滑加速至各自速度上限，由真实模拟精确积分；界面只在状态采样间做短位移平滑。
  暂停冻结真实加速和位移，倍率统一作用于模拟时间。火球飞行加速、命中扩散缓出，不用同一缓动套所有阶段。

## 领地与地板痕迹

- 领地面板与角色/法杖中央工作区互斥，底部共享背包仍可使用；不堆外层大卡片。
- 领地只展示用户需要的城墙/护盾等级、下级收益、价格与实际升级操作；不展示通用成功通知。
- 血迹位于战场单位、角色和法术之下，纯装饰且不捕获指针，不挡住图标、按钮或格子。
  稳定随机形状，不逐帧重新随机；通过真实死亡/水弹命中事件更新，减少动态时不额外抖动或爆闪。
