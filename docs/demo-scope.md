# 一期试玩范围

## 已确认约束
波次守城；怪物从上到下推进并攻击领地；击杀经验与概率金币、清波保底金币及奖励。
多角色、每角色多法杖；多格法术、奥术邻接修饰、可选配方合成；背包打开即暂停且可调整构筑。
角色、法杖、法术、奥术有等级及品级机制，角色还有途径序列与条件节点；本期不做手动等级培养和序列晋升操作；角色已支持个人击杀经验自动升级；已加入同名同品质魔法二合一升品，类型/配置保留，序列属性加成实际参与计算。
素材先用文字、图标、形状；可通过表现映射替换。
AI 走通用 HTTP 语义协议，CDP/Playwright 由外部决定；普通接口只能看到玩家已知信息。
作弊能力由游戏定义并由用户显式解锁；解锁作弊不等于解锁全部图鉴。
人类确认视觉效果；Sol 审代码与架构，运行验证按风险安排。
游戏画面撑满应用视口，HUD、操作、背包、奖励、设置与 Agent 连接均在画面内部。
本阶段不显示游戏名称；左下背包、右上菜单采用无边框纯图标入口。
法杖只呈现真实插槽网格，准备状态位于游戏中央、开始按钮上方；
准备状态显示当前角色的中央编辑器；战斗时隐藏中央编辑器，所有角色的法杖缩略图位于对应角色及护盾、生命条下方，同角色法杖横向排列。
角色工作区原位替换中央法杖；背包为下方固定五行分区，展开挤压游戏区域；不支持调整分区尺寸，列数随屏宽计算。
战斗可暂停，速度按0.25/0.5/0.75/1/2/3/5档统一影响模拟时间。
金币图标和数量放左上；顶部中间仅波次/状态；菜单为全屏二级页面。
角色居中，每个角色用独立绿色环形 Progress 表示个人经验与等级进度。角色下方上下两条 Progress
分别表示护盾和生命，生命用红色，无可见数字/外框/滑块，填色向中间对称收缩。
图标、按钮、文字与面板表面遵循已安装 Inkra 的公开组件与统一间距规范。

## 为试玩采用的临时选择（可调整，非最终产品定案）
自动战斗，角色处于领地前方中央，领地 HP 归零失败。
当前原型领地 HP100、护盾50；伤害先消耗护盾，溢出扣生命；初始未解锁自动修复，城墙与护盾可分别付费解锁和升级自动恢复。
初始一个角色一根 3×3 法杖；奖励可获得第二角色及额外法杖，最多 3 角色、每角色 2 法杖。
法杖独立施法计时，角色共享个人法力；暂停冻结游戏时间，网络时间继续。
每波结束时所有角色法力回满，进入奖励前生效；失败不恢复。
攻击魔法生成真实弹体，接触目标才扣血/死亡/掉落；原目标死亡后弹体继续沿既有方向飞行，能真实碰撞沿途其他怪物，直至命中、越界或到期。
当前闭环内容为48个法术、18种奥术及39条真实合成配方，含穿透、范围、连锁、治疗、护盾、射线、持续领域、召唤与建筑，具体数值见内容数据文档。
可存档的确定性随机源，固定步长；新局使用独立种子，刷新保留本局序列。
游戏进度长期保存在本机浏览器localStorage，关闭后重开同一地址可恢复；自动兼容当前标签页旧存档。战斗过程不连续保存，刷新或重开时重打当前波，之前已结算的成长与物品保留。
无限波次公式可组合多段小怪与首领；右侧进度按实际出生计划标记所有首领节点。
清波四张奖励从可用池随机抽取，不为卡片位置固定类型。同一组不重复同种属性效果、同名魔法或金币（数额不同也只出现一次）；仍可出现四种不同属性加成或四种不同魔法。
每波可用免费刷新次数为floor(波次/10)，进入下一波恢复；付费刷新按本局累计次数取1、3、9、27……金币，跨波不重置，新局重置。幸运奖励提高金币与装备掉落概率，采集奖励与装备提高全队正金币收入，零头持久累计。
升级奖励本期提供物品/恢复/角色/法杖等可用选项，暂不实现升级按钮。
相同法术或奥术可拖放二合一升品质（非等级）：同定义、同品质，神话封顶；
候选只有视觉边框变化，松手才提交，拖离/取消不合。保留目标位置及冷却，不重置资源。
序列用原创途径草案，固定初始序列，成长条件以只读数据保留。

## 必须交付的闭环
开始→自动战斗→击杀与清波→领取奖励→暂停整理法杖→合成→继续下一波。
可以获得和装备第二角色/法杖，完成直接攻击、治疗与构筑闭环。
HTTP/CLI 能观察、操作、订阅关键事件；同一游戏运行时为唯一权威。
人类端与 Agent 不分别实现游戏规则。游戏前台页面连接 HTTP broker，
broker 转发而非运行第二份模拟；手机需能访问同一服务，不保证后台锁屏运行。

## 本期不做
完整美术、最终内容平衡、实际升阶流程、持久化账号、商业部署、
手机原生壳、多人同步和后台战斗。无任务需要为了视觉验收启动自动截图循环。
2026-11-04按用户新要求，将召唤与建筑整合到当前主线；独立旧分支不直接合并，复用当前单一模拟。建筑与召唤物可在合法战场坐标内自由选址，不限定防线附近。



## 个人经验补充（2026-11-04）

每个角色独立累计经验并自动升级，场景中每人显示自己的经验环。当前试玩将击杀经验归实际致死攻击的发射角色，
同角色多个法杖归同一经验池；切换选中或法杖易主不改变已发射弹体的经验归属。
新角色1级0经验，升级赠品仍进入共享背包。旧存档的共享经验只迁初始角色一次，不为历史等级补发赠品。
