# Inkra 线性 Progress 涂色效果需求

来源：无尽巫师游戏使用方，当前消费 @inkra/react 0.15.0。
用户已明确要求整理给 Inkra 补齐；这是通用组件能力，不应由游戏访问私有渲染器实现。

## 使用场景与期望

游戏在虚线防线处展示两条只读状态：护盾在上、生命在下。
希望线性 Progress 能呈现圆形 Progress / CircularSlider 那种铅笔涂色笔触，
而非矩形面板内填色。当前线性实现与圆环不是同一视觉方案。

需要的公开能力：
- 线性笔触/涂色外观，延续现有圆环与 Slider 的稳定纹理、着色和主题语义。
- 可以不显示外框/轨道边界；数字、标签等内容独立控制，可完全不显示。
- 填充起点可选择常规起点或中心。中心模式满值铺满整条，减少时左右两端
  对称向中心收缩；例如50%保留中间一半，0%无填色，100%整条。
- 支持合适的细条高度/粗细。厚度与容器占位一致，不靠放大外框表达进度。
- 颜色可按消费场景的主题语义配置（生命红、护盾蓝），不修改全局主题。

## 语义与工程约束

继续传真实 value/max，保持 role=progressbar 与可访问数值；
不显示数字不等于删除辅助技术语义。不得引入拖拽滑块或调值交互，
也不通过隐藏 Slider 的 thumb 冒充只读 Progress。
沿用现有 Progress 组件演进，属性命名由库维护者确定，不要求本文猜测的新prop。
保持旧调用兼容，纹理 seed 稳定，进度变化尽可能只改变显示范围；
覆盖 reduced-motion、forced-colors、主题/颜色、0/中间/满值及非100 max。
通过公开组件/API、文档和示例交付；游戏方依据实际可消费包接入，不把候选实现说成已发布。

参考：
- https://inkrajs.github.io/docs/components/progress#more-inside-and-outside-the-ring
- https://inkrajs.github.io/docs/components/slider#slider-circular

## 游戏侧的即时调整

等待库能力期间仍使用现有公开 Progress，临时局部样式隐藏外框并居中裁切；
护盾与血条从 lg（24px）改为 sm（12px），条组总高由52px减为28px，
保持组的顶部对齐同一防线。此改动不等于新笔触能力已交付。

## 本地联调与新增配置要求

用户已进一步授权直接引用本机修改版。当前游戏已经以可逆符号链接消费库的公开 dist，
本地候选仍标版本0.15.0，但不同于 npm 0.15.0，尚未发布。
本地模式使用 appearance=stroke/showTrack=false/fillOrigin=center/color/thickness=8，
两条总高20px；正常npm模式保留12px旧适配，两条总高28px。详见 local-inkra.md。

新增要求已转维护方细化：颜色和着色浓度可调；浓度应与整体透明度区分，保留笔触质感；
填色/轨道透明度、宽度、条高及笔画粗细具有明确公开配置或布局方式，尽量统一圆环与线性。
保持默认兼容、局部主题作用域、合法数值范围、稳定seed及缓存；不因value变动重复绘制纹理。
参数名和具体范围以实际构建后的公开类型及文档为准，当前浓度/透明度仍在库任务实现中。
