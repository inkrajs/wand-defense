# 当前试玩交付

2026-11-04。游戏名为“无尽巫师”，本页描述当前实现；视觉效果由用户试玩确认。

## 本轮扩展与性能交付（2026-11-04）

- 真实定义合计112种：48法术、18奥术、18装备、8道具、18怪物、2额外法杖模板；39条配方。完整基础参数从源码生成于 `docs/design/content.md`，机制边界见 `docs/design/mechanics.md`，并有目录完整性测试。
- 三种召唤物与三种建筑接入实际生命、受击、攻击/恢复、存续、任意合法位置部署、一次性费用、暂停恢复、保存和清波延续。新内容通过实际奖励/配方/掉落路径获得，不自动给所有存档灌入新目录；普通Agent不越过知识权限。
- 新奥术支持穿透、迟缓、灼烧、震退、延时、容量、精准；补给增加比例恢复、复合恢复与推进冷却；装备通过真实属性参与编译，普通怪15种与Boss三档共同组成18种怪物。
- 内置目录运行时去掉每tick重复的整状态复制，公开纯模拟、自定义目录和观察快照隔离保留。混合压力样本为60敌人、100初始飞弹、3角色/6法杖、1全状态订阅+1事件订阅，模拟20秒，持续保持battle；同速度前后最终状态与全部事件摘要相同。1倍速tick均值3.976→3.096ms（-22.2%），p95 5.157→4.504ms；5倍速7.198→6.032ms（-16.2%），p95 9.616→8.060ms。每个条件单次Node测量，最大耗时略升，不推断浏览器FPS或所有长帧已消除。前两个无稳定收益的候选已撤回。压力脚本为 `scripts/measure-combat.mjs`，样本生命和领地储备人为提高用于维持压力，不代表正常关卡平衡。
- 菜单、手册、角色、领地、天赋拆包。最终HTML入口加全部同步modulepreload共897,890字节JS，相比前一发布构建1,139,485字节减少21.2%（包含本轮新增内容，并非拆包单独贡献）；缓存所有异步块以保持首次离线访问。PWA v2隔离生产页面验证：断网重载、首次打开菜单和手册成功，角色异步块也在缓存中；恢复网络后关闭测试页，没有修改玩家存档。
- 常用符号保留原字体小子集，避免部分界面为了少数字符额外请求10,354,620字节扩展字体。首屏字体请求仍为1,569,516字节，未将全界面字体节省误称为首屏提速。完整罕用字扩展字体继续按需回退，非强制离线预缓存。
- 本轮最终522项测试通过，类型检查与生产构建通过，固定目录的纯/独占推进全状态等价、快照隔离及自定义目录异常回滚均有覆盖；独立Sol完成模块与整合窄审。视觉效果待用户实际试玩确认。

## 已有机制

- 无限波次自动战斗，多轮普通敌人/精英/Boss节点及下一波预览；怪物从屏外进入，有不同体积、移动方式和攻击动作。普通怪共15种，逐波解锁并混合出现，包含护甲和恢复差异；另有三档Boss。
- 角色各自积累经验、升级和成长，升级及清波恢复法力；角色、装备、法杖、魔法和本局奖励共同参与实际施法计算。
- 队伍共享库存；每个角色有自己的装备和多根法杖，每根法杖保留独立魔法布局。法杖可替换，旧布局不会自动搬到新法杖。
- 当前目录有48种法术、18种奥术、39条真实合成配方、18种装备、8种消耗品、18种怪物和2种额外法杖模板。普通接口及帮助手册按玩家已知信息披露。
- 飞弹按真实路径接触伤害，原目标死亡后继续飞行；包括扫掠碰撞、穿透、范围爆发、射线、瞬时雷链、地面技能和持续区域。
- 命中支持真实击退、迟缓和烧伤：风刃击退，水弹/冰环减速，火球/炎流造成限时周期灼烧。迟缓不无限叠乘，烧伤按来源限量记录，持续伤害击杀仍归原角色；穿透继续沿真实弹道命中多个敌人。
- 雷链立即攻击射程内最近目标，随后逐段传向附近存活且未命中的目标。火场弹/雷场弹能留下持续区域；雷暴覆盖屏内敌人；风暴会移动、牵引并周期伤害，没有宠物生命值。
- 双重/四发/六发按模拟时钟分次连发；分裂产生同时出现的空间分支。迅捷、节能、延展、疾行、广域均进入真实编译结果。
- 随机奖励卡可翻面查看属性，点击卡面领取；品质决定边框，图片使用对应魔法/装备/角色素材。天赋入口查看本局已领取奖励。
- 同组奖励按实际效果去重，不重复同一属性加成、同名魔法或不同数额的金币；已有重复待选奖励在载入时保留首张、补齐不同选项，不重置金币与构筑。
- 奖励可刷新：每波免费次数为波次除以10向下取整，免费优先；付费价格按1、3、9、27递增，本局跨波累计，新局重置。当前奖励、计数及随机状态持久保存；刷新生成新的选项ID，旧领取或旧刷新请求不能误领新卡、重复扣费。
- 奖励新增幸运和采集。幸运影响实际金币/装备掉落概率；采集汇总全队基础、已装备属性与一次本局加成，提高击杀、清波和金币卡收入。小数零头持续累计并保存，付费支出不受增收加成。新增单格饰品采集符，白板采集+10%，品质参与实际缩放。
- 击杀已接真实装备/补给掉落：普通装备基础8%、补给4%，幸运提高装备概率（封顶30%）；Boss保装备且有最低品质。直接进入共享装备/道具库存，无地面拾取模型或泛化成功提示。
- 城墙/护盾可付费修复和无限升级，满值不可修复；自动修复分别付费解锁、升级，随战斗时钟和倍率运行，暂停/失败时停止。
- 正常失败显示本局结算和“重来”；复活仅是游戏允许且明确解锁的作弊能力。
- 地板血迹随敌人强度、致死魔法、时间和波次变化，水系命中可局部清理。

召唤与建筑已按2026-11-04新要求整合：三种有生命值的召唤物、三种可选址建筑，具有受击、存续、攻击/恢复行为。风暴仍是另一类无生命值的限时领域。
序列/途径、品质及晋升条件保留机制，本期没有实际序列晋升操作。

## 界面与组件库

游戏撑满窗口。底部背包固定5行，列数按屏宽计算，以分页容纳更多库存，不支持拖动调整区域大小或上下滚动。
背包分类为魔法、装备、法杖、道具；四类共用网格宽度、顶部4px边距和五行页高，不再为法杖另扣26px宽度或整圈留白，卸载按钮独立锚定自身右上角。默认不重排物品位置，只有主动整理才重新编排。支持拖放装备、魔法、法杖替换和垃圾桶丢弃。
每根详细法杖各有独立外侧右上角卸载按钮；多根法杖水平排列。战斗时不显示中央大法杖，各角色下方在护盾和血条以下显示缩略布局。
角色经验绿环、法力蓝环有间距；入口采用组件库图标和选中涂色。角色/领地/天赋内容复用主题纸色的柔边笔触背景，属性表不再另加实色底。
角色、领地和天赋共用法杖工作区的可用中心与上下边界，底界停在角色经验环上方12px；打开背包后按剩余场景重新计算。天赋标题固定，奖励历史仅在列表内部滚动。桌面及320×740已检查；320×568同时展开五行背包与中央面板时仅余很短的紧凑滚动窗口，完整小屏交互仍需专门设计。
角色详情用满这块有界视口，纵向总留白8px；概览按详情自身可用宽度切换两栏。六个纯图标标签分开概览、雷达、属性、元素、途径、成长；十轴雷达用真实数值按各自参考区间归一化，属性/元素仅常显短名及最终值，悬停/键盘/触屏可查看来源。途径仅显示当前角色所属途径，元素不在途径重复。
菜单和设置入口列表在固定顶部导航下方垂直居中，长内容页继续固定导航并局部滚动。奖励四卡相对场景中央可用区域居中，刷新入口位于卡片下方。

本地 Inkra 候选通过公开API提供线性Progress颜色、浓度、透明度、粗细变化及向中央收缩，PencilShape异形涂色，PencilIcon矩形视口/异形裁剪及InventoryGrid拖放扩展。
游戏通过本地包软链接调试，registry仍为0.15，保留旧版降级路径，不访问库私有绘制器。
魔法整件图稿遵循实际占格形状和实例旋转，透明空格不绘制；不是每个格子重复放一个图标。
技能特效共用Inkra铅笔素材缓存，移动/缩放/透明度变化复用已生成素材；装饰层不决定目标、伤害或资源。水弹及潮涌已校正为圆主体朝向飞行前方、尖尾在后，弹道与碰撞不变。
默认禁止通用“操作已完成”等提示和原始错误码横幅，结果通过实际状态反馈。

菜单的设置下分画面、音乐、控制、调试四个入口，使用Inkra控件。画面配置由独立本地偏好存储管理，修改不改变战斗数值；调整单项自动切为自定义，刷新保留。
所有菜单页共用顶部导航：左上角返回箭头，一级菜单返回游戏，设置详情返回设置，其余子页返回菜单；Escape遵循相同路径。无右上关闭或底部返回按钮，菜单选项间使用公共手绘分割线，暗色沿用统一主题纸色。长页固定标题与分类栏，仅所属内容区滚动。
帮助手册利用宽屏多列展示已发现的图标配方，基础魔法改为紧凑图标带；前置路线按展开加载，品质链使用真实品级颜色，搭配读取真实编译结果。未发现配方只展示匿名总数，不披露名称或图稿。

## 存档与Agent

本机同一浏览器、同一网站地址的localStorage保存准备、奖励、结算等稳定状态，关闭标签页或重启浏览器后可继续；首次读取时仅在长期存档为空的情况下迁移当前标签页sessionStorage里的有效旧存档，不覆盖已有长期存档。开战保存当前波起点，战斗过程不连续写存档。血迹装饰缓存仍属于标签页，仅在战斗外保存。
战斗中刷新重打该波，保留之前的成长与构筑；菜单重来从第0波开始。没有账号、云存档或跨设备同步。
HTTP broker只转发，浏览器运行时为唯一游戏权威。CLI与Skill支持配对、发现操作、事件补读/SSE和已知内容查询；协议不依赖CDP或Playwright。
只需要阶段和事件的存档监听、Agent缓冲使用轻量事件订阅，不再各自复制完整游戏状态；UI仍获得隔离快照，混合订阅顺序与重入队列语义不变。
远程接口不能解锁作弊；只有游戏已允许、玩家已解锁的能力可以执行。普通观察即使作弊开关开启也不披露全部图鉴。

用户明确请求的试玩赠品仅对已识别的旧demo存档一次性补发，不影响正常开局；回执幂等，已消费或丢弃的赠品不会不断补回。
实际前台已确认3根5×5神话Lv.50法杖及首批8个区域法术/奥术到账；第二批4个领域/风暴法术和四发/六发也已收到前台回执：demo存档第28波补发6件，金币和原布局保持。

## 验证与性能边界

本轮奖励刷新、幸运/采集经济和界面分区整合后，整仓467/467测试通过；覆盖刷新计费、旧卡失效、跨波计数、存档恢复、正收入余数与实际到账统计等关键边界。本地及registry兼容类型检查、最终生产构建均通过。
战斗负责人Sol独立检查了真实施法、扣蓝、399ms无伤/400ms首次周期伤害、风暴移动/牵引/存档一致性，以及四种即时雷链；图稿/公共绘制分层经独立Sol源审。
独立浏览器检查了拖放旋转/空格裁剪、五行容量、奖励翻牌领取、射线端点和组件库素材复用；没有进行AI视觉验收。

性能优化包括：战斗停止连续序列化存档；飞弹碰撞复用每步候选；怪物/血条拆分稳定渲染；本地Inkra过滤仅位置变化的样式观察。
同一受控旧fixture（60敌/300飞弹/5倍速）引擎步进中位数由6.38ms降为3.90ms；这不是浏览器FPS。
最新混合压力fixture含60敌、300飞弹、32区域、32连锁、512历史事件，5倍速、120次采样，步进中位数6.47ms、p95 7.96ms。
共享特效512实例素材生成后canvas归零，移动、透明度、resize及重新挂载复用已生成纹理；不为每个粒子重复绘制。
综合开发压力检查另外发现血迹游标每步更新React状态的问题；现改为ref推进游标，只在血迹集合变化时提交，战斗内不写装饰存储。相同极限fixture的60次更新耗时从5.909s降到4.861s，React提交p95由33.2ms降到26.6ms，长任务从18次/968ms降到2次/114ms，更新深度警告由1次降到0次；rAF指标没有同向提升，因此不宣称游戏FPS提高。
飞弹后续改用已测场地尺寸计算屏幕位置、外层transform移动，避免每步改多项继承CSS变量及left/top。两轮同极限生产fixture的样式计算时间下降约30–40%，60次更新总耗时下降约5–14%，警告为0；帧率波动仍明显，不保证60FPS。
用户进一步确认特效密集以及出生/批量击杀均偶发丢帧，追加现实60敌上限的生产profile定位到每个怪物entityId生成独有笔触。改成定义ID+4个稳定槽；覆盖全部槽后，60个全新ID的icon离屏绘制从300份降至0，脚本约2.202s降至17.5ms，只有DOM画布拷贝。库128项LRU仍可能淘汰，不能称永久驻留。
60次真实击杀原来同步绘制血迹产生111ms长任务，现在保持完整随机血迹内存与保存，每rAF最多挂载4个新mark，约503ms全部入DOM、510ms绘制完成，此样本无长任务；暂停冻结待绘队列，非战斗暂停态可恢复历史图像。原颜色/强度/水洗/衰退不改。
冷挂所有怪物与大量特效仍有初次生成成本，完全预热稳态也偶有106ms尖峰，不能声称已消除全部掉帧。完整App追加真实structuredClone通知与较大试玩库存（44种背包魔法+30已装副本、3角色/6法杖、8装备/5闲杖）后，40步20Hz样本约2.593s、脚本996ms，无长任务/新绘制/错误。CPU归因没有证明隐藏InventoryDock/WandBoard是主要热点，未为假设引入冻结投影重构；该短样本也不证明所有偶发尖峰消失。
实际游戏高负载流畅度还需用户设备试玩，原型数值、完整美术/音效和平衡未验收。
