# 雷、风、光、暗、亡灵命名审查

逐项审阅 **237** 个待确认候选，其中 **153** 个列为高风险。同一候选若同时有多项问题，只记主要风险。其余候选暂未列为高风险。其中 19 个节点只有路线、没有独立效果说明，表中已单独注明。效果未写到单节点的，按箭头路线或内部规则判断，不推定已实现。

## 少量改名建议

| 原名 | 候选名 | 依据 |
|---|---|---|
| 交汇风门 | 风喉 | 两路敌群被挤向同一个窄口，“喉”对应进阶地形的收束感。 |

| 聚敌灯 | 迫阵灯 | 灯标出最迫近领地的敌人；不暗示把敌群拉拢。 |
| 骨法遗嘱 | 遗魂印 | 标记法师自己的遗骸供后续重生，既有魂与印的意象，也保留用途。 |
| 湿骨使 | 引潮骷髅 | 明示是召唤物，用潮湿铺垫雷击，适合该分支的起手等级。 |

低阶优先用能读出载体的简短名，中阶用能区分用途的意象，合支终点保留一个鲜明意象。风险表中明确写了玩法近似的节点，宜先决定是否都保留，再改名。

表内七个首选名和「终印」备选已与运行目录及现有目录草案的名称核对，无完全同名。词形近似仍需放回分支一起看。
