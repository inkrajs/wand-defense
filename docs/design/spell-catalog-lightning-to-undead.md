以已上线的 `30a93f2` 为基线。基线 53 ＋第一批确认 33 ＋第二批确认 18 ＋复审后候选 61 ＝ 165。

横线以上为已确认路线，以下新增节点待确认。跨系材料作为连接。箭头表示进阶方向，完整配方、占格和表现待验证。

## 雷（基线 14 · 第一批 6 · 第二批 3 · 待确认 12）

- 静电 → 电荷 → 静电护盾 → 离子护盾
- 静电场 → 雷云 → 闪电风暴
- 静电场＋静电 → 球形闪电 → 雷球风暴
- 感应线圈＋静电场 → 电磁脉冲 → 电磁风暴

---

- 雷矢 → 回路标记 → 双向回路 → 合闸雷 | 雷矢命中留下标记。双向回路沿两个标记拉线，合闸雷在两端都命中时仅释放一次中点冲击。
- 回路标记 → 接地回路 → 合闸雷（进阶材料） | 方向分叉用回路标记×2。横排生成双向回路，竖排生成接地回路，竖向路线把标记间的连线固定为短时截击区。合闸雷使用双向回路＋接地回路。
- 落雷 → 天顶雷标 → 逐标落雷
- 雷链 → 接地针 → 地网泄雷
- 球形闪电 → 往复雷珠 → 对撞雷核
- 离子护盾 → 反击闪电 → 泄荷冲击

## 风（基线 8 · 第一批 7 · 第二批 3 · 待确认 12）

- 风爆 → 风旋 → 龙卷风 → 飓风
- 风爆＋砂刃 → 风墙 → 风暴壁垒
- 风旋＋风暴 → 环流 → 大气环流
- 微风 → 风压 → 真空刃 → 真空风暴

---

- 风刃 → 返航刃
- 风墙 → 导风屏 → 斜风走廊 → 交汇风门 | 导风屏将经过的敌人偏转，斜风走廊沿一条路线推移敌人，交汇风门把两路来敌压向一个出口。
- 导风屏 → 回风槽 → 交汇风门（进阶材料） | 导风屏×2 横排为斜风走廊，竖排为回风槽。回风槽把离开边界的敌人拖回一次。交汇风门使用斜风走廊＋回风槽。
- 龙卷风 → 游走风柱 → 交错风眼
- 风旋＋火苗 → 暖锋 → 强对流
- 真空刃 → 抽空腔 → 真空坍震
- 风暴壁垒 → 卸力风幕

## 光（基线 7 · 第一批 6 · 第二批 3 · 待确认 12）

- 光束 → 聚光 → 激光 → 高能激光
- 光盾 → 光明壁垒 → 棱镜屏障 → 圣域
- 微光 → 星光 → 星辉 → 极光

---

- 聚光 → 焦点束 → 焦点扫描
- 光束 → 反射镜 → 双镜折照 → 镜室光栅 | 反射镜改变射线方向一次，双镜折照延伸到原本打不到的侧面，镜室光栅让两路光束依次扫过交叉点。
- 反射镜 → 回照镜 → 镜室光栅（进阶材料） | 反射镜×2 横排为双镜折照，竖排为回照镜。回照镜沿入射方向返照，优先补打施法者近处目标。镜室光栅使用双镜折照＋回照镜，最多两路且不继续反射。
- 光盾 → 吸光屏 → 回照屏障
- 星光 → 引航星 → 星位迁移
- 星辉＋暗雾 → 照影
- 极光＋电磁脉冲 → 双极辉带

## 暗（基线 15 · 第一批 7 · 第二批 3 · 待确认 12）

- 暗雾 → 蚀印 → 湮灭印记
- 暮光域 → 虚空裂隙 → 虚空风暴 → 事件视界
- 引力井＋蚀印 → 暗星 → 暗星爆发
- 暗烬 → 暗影 → 影子分身 → 暗影军团

---

- 蚀印 → 连环咒标 → 转移诅咒 → 收契 | 连环咒标为敌人挂上限时标记，转移诅咒在目标死亡时找下一个宿主，收契在宿主落空或咒印到期时于最后位置结算。
- 连环咒标 → 封存咒印 → 收契（进阶材料） | 连环咒标×2 横排生成转移诅咒，竖排生成封存咒印。封存咒印固定目标、延迟结算，死亡时留下封存点。收契使用两分支各一份，最多迁移两次。
- 影子分身 → 诱敌替影 → 镜影伏兵
- 鬼火 → 追魂灯 → 灯尽火回
- 虚空裂隙 → 裂缝陷阱 → 闭合界缝
- 事件视界 → 引力轨 → 失轨抛射

## 亡灵（基线 9 · 第一批 7 · 第二批 6 · 待确认 13）

- 骸骨列阵＋尸爆 → 骸骨围城 → 亡灵军团 → 亡灵天灾
- 骷髅法师 → 骸骨法师 → 巫妖
- 骸骨法师＋骸骨列阵 → 骨龙 → 远古骨龙
- 骨片 → 骨甲 → 骨墙 → 骨牢
- 墓响 → 幽魂 → 怨灵 → 幽灵军团

---

- 骨甲 → 散骨反刺 → 骨甲继承
- 骨牢 → 囚魂环 → 魂锁交接
- 骷髅射手 → 遗骸箭库
- 巫妖 → 魂匣 → 轮换魂匣
- 尸爆 → 延时尸火 → 尸火接力 → 墓场点火 | 延时尸火消耗一具遗骸定时起爆，尸火接力只在爆区接触另一具遗骸时继续，墓场点火允许先布设一处起火点并选择最近的遗骸开始接力。
- 延时尸火 → 守墓尸火 → 墓场点火（进阶材料） | 延时尸火×2 横排为尸火接力，竖排为守墓尸火。守墓尸火在敌人踏入时触发，等待到期即熄灭。墓场点火使用两分支各一份，单次最多消耗三具遗骸。
- 复生 → 借骸 → 选骸复生
