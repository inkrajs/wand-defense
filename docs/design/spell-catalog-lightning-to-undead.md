以已上线的 `30a93f2` 为基线。基线 53 ＋第一批确认 33 ＋第二批确认 18 ＋复审后候选 237 ＝ 341。

横线以上为已确认路线，以下新增节点待确认。跨系材料作为连接。箭头表示进阶方向，完整配方、占格和表现待验证。

## 雷（基线 14 · 第一批 6 · 第二批 3 · 待确认 47）

- 静电 → 电荷 → 静电护盾 → 离子护盾
- 静电场 → 雷云 → 闪电风暴
- 静电场＋静电 → 球形闪电 → 雷球风暴
- 感应线圈＋静电场 → 电磁脉冲 → 电磁风暴

---

- 雷矢 → 回路标记 → 双向回路 → 合闸雷 | 雷矢命中留下标记。双向回路沿两个标记拉线，合闸雷在两端都命中时仅释放一次中点冲击。
- 回路标记 → 接地回路 → 合闸雷（进阶材料） | 方向分叉用回路标记×2。横排生成双向回路，竖排生成接地回路，竖向路线把标记间的连线固定为短时截击区。合闸雷使用双向回路＋接地回路。
- 落雷 → 天顶雷标 → 逐标落雷
- 雷链 → 接地针 → 地网泄雷
- 球形闪电 → 往复雷珠 → 对撞雷核
- 离子护盾 → 反击闪电 → 泄荷冲击
- 接地针 → 避雷柱 → 雷池塔 | 避雷柱拦截范围内第一枚友方雷矢，将其剩余威力折成一次近处放电，原雷矢消失。雷池塔存两次拦截，满载后沿固定直线放一次电，存量随塔消失。
- 雷云 → 电雨桅 → 云栖雷灵 | 电雨桅每次只在首个敌人穿过警戒线时落雷。雷灵主动换位到两座友方桅杆之间，每完成一次换位只落一道雷；没有桅杆时改为原地落雷。
- 天顶雷标 → 雷桥 | 天顶雷标＋雷矢合雷桥，固定两枚有效雷标的落点并在两点间放电。标记目标离开后线路仍有效，最多一段，不从敌人继续传导。
- 逐标落雷 → 接续雷 | 逐标落雷＋回路标记左右贴合合成。首个标记目标死亡时，雷从遗留落点跳向下一个有效标记；只接续一次，无有效标记则结束。适合依赖低血量小怪续接的构筑。
- 导电潮 → 截潮雷 → 沿岸导电 | 导电潮＋雷矢合截潮雷（一枚雷系投射物），只在首个潮湿敌人受到正伤害时停弹，交给现有潮湿反应结算。截潮雷＋水弹合沿岸导电，消耗命中目标的潮湿后只选沿来路一侧的活敌；没有候选就沿用原地放电。每发至多消耗一份潮湿。
- 雷链 → 雷针陷阱 | 雷链＋静电合成。第一处被护甲完全抵消的接触留下雷针，下一名实际经过针位的敌人受击一次。零伤碰撞不施加状态，针位到期作废。适合用低伤快攻为敌军后排布陷阱。
- 静电场 → 湿地雷栅 → 跨线警雷 | 静电场＋泥沼合湿地雷栅，仅以受到正伤的潮湿敌人触发一次截击，方便将水系减速区留作防线；湿地雷栅＋雷网合跨线警雷，用同一次潮湿反应优先打另一侧最靠近领地的敌人，兼顾双线但不增加传导次数。
- 静电场＋回春 → 护阵电圈 | 以站在领地一侧的友方构造为中心布电圈，敌人贴近后放电一次，适合保护容易被绕到身旁的治疗构造。
- 雷矢＋钢针 → 破甲电针 | 先由钢针路径打出单发实体；若正伤命中已有暴露的敌人，就沿原路径穿过该目标一次，适合破甲配队。
- 破甲电针＋雷网 → 截流雷网 | 穿透暴露敌人时把射线余程换成一次网格截击，借前排的破甲开出防守窗口。
- 落雷＋震退波 → 追落雷 | 正伤击退后把这次落雷的瞄点改为受击者实际停下的位置，适合向已铺好的领域推敌；每次只追一名，落雷不再击退。
- 追落雷＋霜纹塔 → 截退雷 | 若被推出的敌人停在一座友方霜纹塔附近，落雷改打那里离领地最近的敌人，适合把位移转成援防；至多改一次，找不到活敌时保留原落点。
- 雷矢＋微风 → 漏网电矢 | 选取本侧最近且身上没有减速的活敌发一枚雷矢，适合已有风系减速但仍有漏网者的一侧；没有候选则不施放，每次只选一名。
- 电弧＋光矢 → 校线雷 | 先用直线光标指示通路，电弧只在路径内选点，适合避免被侧路杂兵拉走。
- 校线雷＋落雷 → 断线落雷 | 线路没有合法中继时把该次落雷投到光标末端，适合把无目标时的电弧换成封口。
- 跳电＋骨片 → 骨导雷 | 以范围内一具未预留敌骸作跳点并立即消费，适合隔着空隙打击下一波前锋。
- 骨导雷＋尸爆 → 带电尸爆 | 把同一具跳点遗骸用于定点爆炸，消费后不再把它当跳点，适合选择用资源守入口。
- 雷网＋风刃 → 越线电网 | 一段横向短线只击中真正从外侧跨进来的首敌，适合留网堵追击目标。
- 越线电网＋霜滴 → 破冰电网 | 过线时仅消耗首个有效冻结，用短电弧替代普通网击，适合把冻结留给入口再爆发。
- 球形闪电＋陶土 → 落地雷球 | 投射物第一次撞到合法地面后停住并成为落点，适合提前守门而非追敌。
- 落地雷球＋震退波 → 推雷 | 一次正伤击退可把雷球原实体推到邻近空位，保留剩余寿命，适合在两线之间搬动火力。
- 落雷＋微光 → 护塔惊雷 | 只在附近构造遭受正伤时锁定攻击者脚下，适合防快速拆塔的敌人。
- 护塔惊雷＋回春 → 停雷救援 | 受击构造已濒毁时将该次落雷替换为一次治疗，适合优先保住关键塔。
- 电磁脉冲＋铁砂 → 引针雷 | 在首次正伤命中后向尚未命中的高甲活敌投一枚不传导的铁针，适合给分散重甲补刀。
- 雷场弹＋回春 → 断电塔 | 领域脉冲只在相邻守军死亡时触发一次，取死亡点作落雷中心，适合牺牲一线后阻止突破。
- 静电＋霜滴 → 霜线雷 | 命中已有冻结的敌人时保留冻结，把这次电击改射冻结目标后方的首名活敌，适合用控住的前排作跳点。
- 风暴之矛＋暗烬 → 熄火雷枪 | 命中正在灼烧的目标时消费本施法者的一层剩余灼烧，把一次落雷放到该目标背后的敌群，适合在急需后排伤害时放弃持续输出。
- 电荷＋墓响 → 静电封骸 | 一次雷击真正击杀敌人后只记录它落下的遗骸，下一次同侧电击可以就近向该遗骸旁边的活敌放电而不消费遗骸，适合与亡灵共享资源。
- 静电封骸＋光盾 → 遗骸警报 | 标记敌骸被任何技能消费时，只为其所在侧留一道短时雷警，第一名过线者触发一次，适合把己方尸爆作为换防信号。
- 雷场弹＋微风 → 空线留雷 | 远端当前没有活敌时，将该次法力留给第一名真正跨入该线的敌人，等待至多一段冷却且期间禁投近线，适合押注空线即将来敌。
- 雷网＋耀环 → 断后电栅 | 两线都有敌时只攻击上一轮受过伤却未被击退的一侧，放弃另一侧的首发，适合把第二道防线留给已漏过控制的敌人。

## 风（基线 8 · 第一批 7 · 第二批 3 · 待确认 41）

- 风爆 → 风旋 → 龙卷风 → 飓风
- 风爆＋砂刃 → 风墙 → 风暴壁垒
- 风旋＋风暴 → 环流 → 大气环流
- 微风 → 风压 → 真空刃 → 真空风暴

---

- 风刃 → 返航刃
- 风墙 → 导风屏 → 斜风走廊 → 交汇风门 | 导风屏将经过的敌人偏转，斜风走廊沿一条路线推移敌人，交汇风门把两路来敌压向一个出口。
- 导风屏 → 回风槽 → 交汇风门（进阶材料） | 导风屏×2 横排为斜风走廊，竖排为回风槽。回风槽把离开边界的敌人拖回一次。交汇风门使用斜风走廊＋回风槽。
- 龙卷风 → 游走风柱 → 交错风眼
- 风旋＋火苗 → 暖锋 → 强对流
- 真空刃 → 抽空腔 → 真空坍震
- 风暴壁垒 → 卸力风幕
- 返航刃 → 风筝斥候 → 牵风哨 | 斥候携带一枚返航刃，归还前不发下一枚。牵风哨固定返航终点，让回程刃线能够命中原路径之外的敌人。每发只去返各一次。
- 导风屏 → 风门座 → 对开风阀 | 风门座朝部署方向推开首个跨门敌人，随后关闭至下一冷却。对开风阀交替启用两侧出口，某侧无敌人时保留朝向和这一拍。
- 风门座 → 助跑风道 → 换向风门 | 助跑风道仅加快场内友方构造。助跑风道＋对开风阀合换向风门，先给己方加速，首次发现敌人反向闯入便切为敌方减速门，单次部署只切一次。
- 穿风刃 → 折角风刃 | 穿风刃＋风刃合成。第一名受到正伤的敌人成为折点，飞刃按预设朝向转一次直角，适合打相邻阵列。第一段已命中的敌人排除于第二段。
- 风压 → 退路风幕 | 风压＋风刃合成。真实击退后，以被击者起点为准留下短时减速区，保护被敌人压近的空位。一次施放只留一处，风幕不再记录击退。
- 震退波 → 分兵风口 → 逆风缓冲 | 震退波＋潮涌合分兵风口，首次击退时将目标推向附近已有的友方减速区，适合一侧先铺控制；分兵风口＋岩弹合逆风缓冲，遇到未被推离原位的敌人时，把本次击退改为在其脚下生成短时减速区，适合一侧出现难推动的敌人。
- 风刃＋骨片 → 引兵风标 | 风刃首个正伤落点立一个短时风标，同侧召唤物保留当前攻击，空闲后才向风标靠近，适合远处提前部署。
- 引兵风标＋回春 → 护送风阵 | 风标变为只接收撤回单位的会合点，到达的一名受损召唤物接受一次治疗，适合保住贵重前锋。
- 风压＋陶土 → 定风障 | 将减速风障固定在一处合法地面，友方近战穿过不受影响，给重型敌人留出可预期的接战位置。
- 定风障＋地刺 → 伏风阵 | 第一个减速敌人离开风障时在出口触发一次地刺，用撤退线路作陷阱。
- 穿风刃＋电弧 → 引雷风刃 | 第一次正伤穿透后，以实际命中点为起点放一次短电弧，选刃线之外最近的活敌，适合一条路径打纵队、另一条路径打侧面漏网敌人；电弧不再连锁或触发潮湿。
- 风刃＋静电 → 挡路风刃 | 沿瞄准线命中的首名带感电标记的敌人停弹并被短暂推离路线，保留感电给后续雷术消费；适合先由队友标记、再为后排清出射线，单发只处理一名。
- 风刃＋霜滴 → 偏风刃 | 对已减速敌人造成正伤后从它侧边通过一次，适合利用冻慢的前排打后排侧翼。
- 微风＋棘种 → 护苗风 | 只将首个接近一座友方植物构造的敌人吹离其近战位，适合保护静止建筑。
- 护苗风＋钢针 → 穿林风矢 | 友方构造在路径上时保留本发钢针并从其旁侧穿出，适合拥挤阵地，最多绕一个友军。
- 风墙＋岩弹 → 斜坡风 | 对能被推开的敌人只沿部署线滑移，若敌人贴着阻挡物则停止，适合把敌人推向岩墙一侧。
- 斜坡风＋暗雾 → 跌入风眼 | 敌人实际被阻挡物截停时在该点牵引一次，适合将推不动的队列留给领域。
- 风旋＋光矢 → 逆向截风 | 作用于迎着风旋移动的首名敌人并在原地减速，适合拦从反向突入的敌人。
- 穿风刃＋定时触发 → 回头风剪 | 飞刃首次出界前回到原瞄准线上从后向前切一次，适合敌人躲过正面路径。
- 风刃＋回春 → 护航风 | 方向线上第一个友方召唤物受击后，原点留下短时缓行区以保护退路，适合无需改变召唤物行动的远程掩护。
- 风爆＋火花 → 散火风 | 首次正伤击退后把同一施法者的一层灼烧转给落点附近另一名敌人，保留时限，适合换一个持续伤害目标。
- 风墙＋光矢 → 封箭风 | 只截下飞行中的第一枚己方风刃并消耗它，换成墙外一次背向冲击，适合把原本打空的弹道用于防线。
- 微风＋铁砂 → 钉地风 | 在合法地面定一个短时止步点，首个已被击退的敌人到点时才减速，适合和击退技能合用。
- 斜坡风＋回春 → 顺风伤员 | 放弃推敌，召唤物在风障内低血时优先治疗离领地最远的一名，适合无法撤回的前锋，治疗后立即结束风障。
- 风暴＋光矢 → 引空风 | 场上只有近线有敌时，把空置远端风暴移到原部署附近，继续用剩余脉冲击退近线敌人，适合不想白等远线来敌；单次只收回一次。

## 光（基线 7 · 第一批 6 · 第二批 3 · 待确认 41）

- 光束 → 聚光 → 激光 → 高能激光
- 光盾 → 光明壁垒 → 棱镜屏障 → 圣域
- 微光 → 星光 → 星辉 → 极光

---

- 聚光 → 焦点束 → 焦点扫描
- 光束 → 反射镜 → 双镜折照 → 镜室光栅 | 反射镜改变射线方向一次，双镜折照延伸到原本打不到的侧面，镜室光栅让两路光束依次扫过交叉点。
- 反射镜 → 回照镜 → 镜室光栅（进阶材料） | 反射镜×2 横排为双镜折照，竖排为回照镜。回照镜沿入射方向返照，优先补打施法者近处目标。镜室光栅使用双镜折照＋回照镜，最多两路且不继续反射。
- 光盾 → 吸光屏 → 回照屏障
- 星光 → 引航星 → 星位迁移
- 星辉＋暗雾 → 照影
- 极光＋电磁脉冲 → 双极辉带
- 引航星 → 星灯座 → 逐星灯塔 | 星灯座短时标出最先进入的目标。逐星灯塔等该目标脱离或死亡再换标一次，并向上一个目标位置补照；复用标记与定向光束。
- 吸光屏 → 储光盏 → 转照台 | 储光盏记录领地护盾一次实际吸收量。转照台把储备转为对最近受损友方构造的一次治疗，治疗量低于原吸收量且受上限约束。每座台只存一份，新记录覆盖旧值。
- 照影 → 聚敌灯 | 照影＋光矢合成，标出离领地最近的敌人，本法术每轮优先攻击该目标。适合有多个方向同时来敌时保住领地。
- 焦点扫描 → 首尾轮射 | 焦点扫描＋微光合成，交替攻击最前与最后两名不同活敌；只有一名目标时正常射击。用一件法术兼顾前排和尾部敌人。
- 光矢 → 破甲追针 | 光矢＋聚焦合成，只在已暴露的敌人受到正伤时，从其受击侧追加一针。依赖破甲构筑，单次施放只追加一次。
- 焦点束 → 锁定光束 → 残光扫射 | 焦点束＋光矢合锁定光束，后续脉冲只打首个实际受伤且仍在束线内的目标。锁定光束＋微光合残光扫射，目标离线后结束原束，在末次有效命中处扫一次，适合持续移动的队列。
