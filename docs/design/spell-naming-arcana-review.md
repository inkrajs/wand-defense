# 奥术候选命名审查

逐项审阅了有效映射的 182 个候选，确认 slug 无重复。已确认定义和草案内的删并记录用于对照。命名高风险 147 项，其余 35 项本轮无需优先改名。每个高风险 slug 只列一行，同时符合几项问题时合并记录。命名风险以玩法映射为准，同质项的机制区别仍见右栏。

- **动作说明**读起来像施法指令或一句效果摘要。**工程与界面术语**突出实现方式或面板状态。**抽象或误导**意味着玩家难从名字推断真实触发、目标或结果。**组内同质**表示同一支的名字难以快速区分。
- 原位护法之后是「镇界铭 → 断烽咒」这一组试拟名。一阶用铭刻法阵划定炮塔守区，进阶在炮塔遭击毁时兑现该法阵终结段。
