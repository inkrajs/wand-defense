## 施法顺序与发射形态

- **连锁施法** → **多重连锁**
- **扇射** → **轮转齐射**
- **二次分裂** → **连续分裂**
- **多重连锁** → 序列施法 →（交错施法 → 接续施法 ／ 错峰齐发 → 分段预付）
- **轮转齐射** → 定轴齐射 → 对向齐射
- **连续分裂** → 定距分岔 → 归束分流

## 复审记录

- 将「霜层计数」「湿路选线」「裂纹探测」三组收束为四个通用候选。转移状态把剩余持续时间搬给另一目标，隔离状态阻止继续传播，状态转化按白名单替换状态，消耗状态提前结清其剩余效果。碎冰、超导、弱点打击保留各自已确认身份，可作为分支材料。
- 合并「序列槽」「同步拍」为「序列施法」，让相邻载荷按固定次序释放。交错施法在载荷之间轮替，错峰齐发在一次施法里分时释放。删除「扫角反转」「双轴交射」「宽角分流」等只改数量或角度的同类项。
- 删除「岗位协议」「脉冲时窗」等仅给配置起名的中间节点。删除依赖敌人改道、复杂编队或额外弹道图层的「侧翼包夹」「沿迹传染」「内缘净空」等设想。接防只交换已有构造物的选敌优先级，遗骸路障只落下有限存续的现有建筑实例。
- 草案优先复用弹道、光环、印记和构造物。连锁载荷独立执行。转移、转化、返还法力、承伤均需明确白名单和结算顺序，并受每次施法、每个目标及存活实体上限约束。
- 高阶合成优先使用一件上一阶、最多两件辅助材料，排除同配方三个 3×3 定义。确认后对每个具体格形做 5×5 实际合成验证，并检查资源循环、阶段预算、特效可读性和存档兼容。

八条深化路线按邻接解锁。材料说明中的候选奥术暂按 2×1 或 3×1 连续格估算，并排配对须共享格边。序列朝向以同一个奥术相邻两侧判定。构造协同、法力托管与冷却透支不跨波转移。
