# Inkra InventoryGrid 可组合布局需求

当前消费版本：@inkra/react 0.15.0。已提交给 Inkra 维护聊天，尚不代表发布。

游戏使用 Resizable 将场景与背包分为上下区域：下方只有分类和三行真实形状库存，
上方保留可编辑法杖或角色装备。背包元素需能跨区拖到合法法杖/装备容器。

目前公开 InventoryGrid 只接受完整 containers 模型和 renderItem，不能把各容器独立放进
不同的布局节点。游戏可暂用一个共享 Grid 跨区布局，以 Resizable 的公开布局回调提供尺寸，
集中 CSS 定位现有容器；这耦合当前容器 DOM，不是理想的长期通用接口。

期望公开能力由库选择：例如受控共享 Root 和独立 Container，或等价的容器布局入口。
保持现有 InventoryGrid 用法兼容，复用受控模型、跨容器拖放、键盘、旋转、放置校验和无障碍。
游戏的归属、装备容量与交易仍由 runtime 命令校验，组件只负责交互与布局。
不要求库提供游戏装备规则，不访问私有 renderer 或自行复制 DOM 命中算法。

验收场景：同一组受控 containers 分别挂在上下 Resizable 区域；调整面板高度后可继续
鼠标/触摸/键盘跨容器移动；拒绝交易不丢失物品；原单组件布局无破坏。

交付时区分源码实现、测试、可消费包与发布版本，游戏仅在获得实际公开 API 后替换适配。
