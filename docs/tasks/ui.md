# 无尽巫师界面模块

状态：当前界面已集成，视觉效果由用户确认；整仓提交与最终集成由根协调者负责。

## 实现与边界

- `App` 订阅单一 `RuntimePort` 并派发命令。场景角色、角色详情、法杖和库存共享当前角色；角色选中底色位于法力环内。准备态法杖与开始按钮作为一组定位，战斗时法杖缩小并禁止编辑。
- 背包固定三行可视高度、按可用宽度计算列数；超出时纵向滚动。魔法与装备分别保持布局，共享列数与容量；移动、合并和物品返回时尽量保持原位置。布局缓存只在当前运行会话内，重启后重新初始化。极端超宽或超大自定义形状不保证可访问。
- 装备分类打开角色详情，当前角色的法杖槽使用同一库存网格的投放目标；魔法分类返回法杖工作区。local Inkra 候选包支持完整占格的元素填色、品级描边和同品质合并；registry 0.15 使用兼容回退，缺少这些候选包的新能力。
- 角色页仅展示图标装备槽、简短概览与属性雷达等；奖励卡在中央呈现，领取和翻面热区独立，详情可滚动。操作状态不额外显示在画面上。右下方角色与领地入口切换场景内工作区；领地升级使用共享规则和运行时命令。
- 角色与防线的经验、法力、盾和生命条共用场景锚点；本地 Progress 使用公开 stroke 参数与颜色，registry 0.15 使用兼容裁切。盾/生命条本地密度为 1.05、不透明度为 0.88，环为 1.35/1。金币、波次、速度、暂停、菜单和设置由运行时状态驱动。
- 新局重置 UI 暂态。菜单保持 Agent 组件挂载，设置持久化文字效果、减少动态与音乐偏好（目前无音乐音源）。玩家合并相同魔法通过 local Inkra 公开交互；不同物品配方的人工合成入口尚未恢复，运行时能力保留。
